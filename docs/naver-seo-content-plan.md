## 3. 전략 판단 — "칼럼만으로는 안 된다"

요청은 "칼럼으로 콘텐츠를 짜자"였지만, **96개 중 약 90%가 상업 의도(구매 직전) 키워드**다.
네이버는 이런 검색어에 대해 `플레이스 → 파워링크 → 블로그/카페 → 웹사이트` 순으로 노출하며,
**웹사이트 영역에서는 칼럼(정보성 글)보다 서비스/랜딩 페이지가 우선**한다.

따라서 2계층으로 나눈다.

```
[1층] 랜딩 페이지  ← 상업 키워드 (구매 직전) — 돈이 되는 축
[2층] 칼럼         ← 정보성·롱테일·업종 사례 — 유입을 만들고 1층으로 보냄
```

| 항목 | 기준 | 이유 |
|---|---|---|

| 소제목 | H2 3개 이상 + H3 | 구조화된 문서 우대 |
| 숫자·사례 | **필수** | 보유 자산이 강력: 누적 조회수 3.1억, 크리에이터 18명, 총 팔로워 72만 |
| 내부 링크 | 해당 랜딩으로 1~2개 | 상업 페이지로 권한 전달 |
| 발행 주기 | **주 2회 고정** | 네이버는 발행 규칙성을 신뢰 신호로 사용 |
